# Security policy

BridgeKit is experimental. Latest source is the supported place for fixes; no maintained LTS versions or complete Chrome security-equivalence guarantee is offered.

Do not post exploitable details or credentials publicly. This repo is currently private, but verify visibility/recipients before reporting sensitive material. If GitHub private vulnerability reporting is enabled, use Security → Report a vulnerability. Otherwise contact @babymonie through an existing private channel to arrange a report. No public security email is designated.

Provide affected commit/version, app/runtime versions, minimal synthetic reproduction, boundary and impact. Do not send profiles, tokens, passwords, full app archives or private user data.

Intended boundaries are documented in [security model](docs/security.md). Bypasses are relevant even if an affected third-party extension is otherwise unsupported.
