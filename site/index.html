GET STARTED

Install BridgeKit

Release v0.5.0 ↗

1. Set up the desktop picker

Install Node.js 22 or newer and Git. Run these commands in a terminal. You can also extract the release’s source ZIP, open a terminal in that folder, and run the last two commands.

git clone https://github.com/babymonie/bridgekit.git
cd bridgekit
npm ci
npm start

Run npm run demo to try plugins in an offline demo.

2. Patch a compatible app

In the picker, select an installed app or add its folder. Read the compatibility result, choose the app pages that plugins may access, and fully exit the target app. Use Review patch to check the backup and file changes.

Reopen the app normally. Press Ctrl + Shift + B or use the Bridge tray icon. To undo the patch, close the app and choose Restore original in the picker.

FACEIT

Windows preset

The preset accepts the original archive hashes for Windows builds 2.10.0 and 2.11.0. If the status check reports an unknown build, leave it unpatched and request support for your version.

Finish any active match and fully exit FACEIT, including the tray process. From the BridgeKit folder, check the status and install.

npm run faceit:status
npm run faceit:install

Reopen FACEIT and press Ctrl + Shift + B. With FACEIT closed, use npm run faceit:uninstall to restore the original archive.
