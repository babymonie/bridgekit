# Wand Game Notebook — Bridge SDK plugin

Keep per-game notes, build ideas and next-session reminders. Up to 8 games with 1,500 characters per note. Notes stay on this device and survive disabling the plugin. Use current page title is an optional suggestion, not automatic game detection. It requires an allowed Wand page; manual names work independently.

Install this folder or its ZIP through Wand’s Bridge plugin manager, then enable it and open Settings. Requires the BridgeKit app profile ID `wand`. Permissions: `panel` for settings, `storage.local` for the notebook, `page.read` only for the title button. No page scripts, filesystem/process access, network requests or game modification.

Save before switching games. Deleting requires clicking Delete game and then Confirm delete. Uninstalling preserves Bridge SDK saved settings. See ../../docs/wand-plugins.md for setup and verification limits.
