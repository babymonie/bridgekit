# Roadmap

## Available prototype

- FACEIT Windows adapter for inspected hashes and a separate bench.
- Persistent registry, folder/ZIP imports, list/search, review, settings, enable/disable and uninstall.
- SDK panels, scalar settings, HTML/CSS/scripts and cleanup.
- Selected native MV3 integration with explicit limits.
- Independent tray/shortcut manager and style-only Ad Cleaner.
- Reversible installer/update/rollback.

## Next work

1. Targeted native API gaps: Repeek management/polyfill, offscreen, sync contexts and optional host grants.
2. Qualify newer FACEIT builds with build-specific evidence and diagnostics.
3. Add reviewed requested adapters, preferring source hooks.
4. Package update/review flow and supported-API diagnostics.
5. Broader windows/sessions/restart integration coverage.

No delivery dates promised. Marketplace, Web Store download, automatic app/plugin updates, macOS/Linux patch installers and full Chrome emulation are not implemented.
