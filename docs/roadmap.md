# Roadmap

## Available in 0.5

- Desktop installed-app scanner, search/filter, manual paths, explicit blockers and review dialogs.
- Generic hash-pinned app profiles and reversible ASAR patch/update/restore for packed CJS/ESM entries.
- Exact web/custom-protocol origin and local HTML page policies; SDK mode works without native Chrome sessions.
- Read-only Electron fuse checks, ownership inventory, stopped-app guards and operation locks.
- Preserved FACEIT exact-build preset and installation/data format.
- Per-app plugin management, optional app-target metadata, SDK capabilities and partial native compatibility.

## Next useful work

1. Qualify real third-party builds beyond generated fixtures; improve runtime preference/startup diagnostics.
2. Handle additional layouts through supported integration routes, without weakening signing/integrity protections.
3. Improve discovery coverage and package/update diagnostics across platforms.
4. Address native gaps: management/polyfill, offscreen, sync contexts and optional-host acquisition.
5. Expand windows/sessions/restart integration coverage.

No delivery dates promised. Candidate is not verified support. macOS signed-bundle patching, unpacked archive patching, marketplace, Web Store downloading, automatic app/plugin repatching and full Chrome emulation are not implemented.
